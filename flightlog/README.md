# Drone Flight Log

iPhone web app for logging drone flight hours by type and date.

- **Live app:** https://rons2438.github.io/flightlog/
- **Manual:** https://rons2438.github.io/flightlog/manual.html (open in Safari and use Share > Print > Save to Files for a PDF copy)
- **Install:** open the live app in Safari on iPhone, tap Share, then Add to Home Screen.

Flight data is stored only on the iPhone (not in this repo). Use Settings > Back up to iCloud to save a backup file, and Restore from Backup to load it on another iPhone.
